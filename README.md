# Nook by Jina

Website resmi Nook by Jina, dibangun menggunakan Next.js.

## Menjalankan Project

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka http://localhost:3000 di browser.

## Teknologi

- Next.js
- React
- TypeScript
- Supabase

## Deployment

Project ini disiapkan untuk deployment melalui Vercel.
